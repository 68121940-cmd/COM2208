1.ความหมายของเทคโนโลยี
คือ การนำความรู้ทางวิทยาศาสตร์ ความรู้ทางวิชาการ และความคิดสร้างสรรค์มาประยุกต์ใช้ในการสร้างเครื่องมือ อุปกรณ์ หรือวิธีการต่าง ๆ เพื่อช่วยอำนวยความสะดวกในการดำเนินชีวิตและการทำงานของมนุษย์ รวมถึงช่วยแก้ไขปัญหาและเพิ่มประสิทธิภาพในการทำงานให้ดียิ่งขึ้น เทคโนโลยีมีการพัฒนาอย่างต่อเนื่องตามความต้องการของสังคมและยุคสมัย
ตัวอย่างเช่น ปัญญาประดิษฐ์ (AI) ช่วยวิเคราะห์ข้อมูลและสนับสนุนการเรียนรู้

2.ความหมายของนวัตกรรม
คือ การนำความรู้ แนวคิด ความคิดสร้างสรรค์ และเทคโนโลยีมาพัฒนาสิ่งใหม่ หรือปรับปรุงสิ่งที่มีอยู่เดิมให้มีคุณภาพและประสิทธิภาพมากยิ่งขึ้น โดยมีจุดมุ่งหมายเพื่อแก้ไขปัญหา ตอบสนองความต้องการของผู้ใช้ และสร้างประโยชน์ให้แก่บุคคลหรือสังคม ซึ่งนวัตกรรมไม่จำเป็นต้องเป็นสิ่งประดิษฐ์ใหม่ทั้งหมด แต่อาจเป็นการนำสิ่งเดิมมาปรับปรุงให้มีรูปแบบหรือวิธีการใช้งานที่ดีขึ้น
ตัวอย่างเช่น เกมการศึกษา ช่วยให้ผู้เรียนเรียนรู้ผ่านการเล่น

3.ความหมายของ Design Thinking
คือ กระบวนการคิดแก้ไขปัญหาอย่างเป็นระบบ โดยเน้นการทำความเข้าใจความต้องการและปัญหาของผู้ใช้เป็นสำคัญ เพื่อนำข้อมูลมาวิเคราะห์ คิดค้นแนวทางแก้ไข และพัฒนาสิ่งใหม่ที่ตอบโจทย์ผู้ใช้ได้อย่างเหมาะสม เป็นกระบวนการที่ส่งเสริมความคิดสร้างสรรค์ การคิดวิเคราะห์ การทำงานร่วมกัน และการทดลองเพื่อให้ได้ผลลัพธ์ที่ดีที่สุด
ตัวอย่างเช่น การพัฒนาเกมการศึกษาเพื่อแก้ปัญหานักเรียนไม่สนใจเรียนวิชาคอมพิวเตอร์
